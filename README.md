## FVisual

| Команды | Что значит |
| :--- | :--- |
| **/fvisual list** | Показывает всех игроков с данным модом. |
| **/fvisual icon** | Установить себе иконку размерами 64x64 или 256x256. |
| **/fvisual icons [on/off]** | Показывать иконки других игроков. |
| **/fvisual support** | Связь с автором. |
| **/fvisual help** | Показать команды. |

## 🚀 Установка

1. Установите **Fabric Loader** версии `1.21.11` для соответствующей версии Minecraft.
2. Скачайте `.jar`-файл мода из раздела **Releases**.
3. Поместите файл в папку `.minecraft/mods`.
4. Запустите игру.

### 📋 Зависимости
*   **Fabric API** (обязательно для Fabric-версии).
